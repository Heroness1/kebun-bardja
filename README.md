# Kebun Bardja

A responsive, editorial-style landing page for Kebun Bardja, a fruit-growing brand focused on avocado, durian, and its orchard story.

## Stack
- Next.js App Router
- React
- CSS animations and Intersection Observer reveal effects
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Before launch
- Replace the generic WhatsApp link with the official business number.
- Confirm the orchard address, location/map, business hours, and real contact channels.
- Replace sample stock photography with approved photos from the actual Kebun Bardja orchard and harvest.
- Confirm fruit varieties, seasonality, availability, and any cultivation claims before publishing.
- Add the production domain to metadata and configure analytics only after the correct property/IDs are available.

## Notes
The design intentionally avoids unsupported claims about certifications, organic status, exact location, and guaranteed harvest availability. Animations respect `prefers-reduced-motion`.
